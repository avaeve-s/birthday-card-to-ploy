# การ์ดวันเกิดออนไลน์ — Happy Birthday Ploy 🎀

ธีมน่ารัก โทนพาสเทลชมพู-เหลือง คลิกที่ซองเพื่อเปิดอ่านคำอวยพร มี confetti, รูปภาพ, และเพลงคลอ

## ไฟล์ที่ต้องเตรียมก่อนอัปโหลด

1. **photo1.jpg** — รูปของพลอยที่จะโชว์ตอนเปิดการ์ด วางไว้โฟลเดอร์เดียวกับ `index.html`
   (แนะนำรูปแนวตั้งหรือสี่เหลี่ยมจัตุรัส จะเข้ากรอบโพลารอยด์สวยที่สุด)
2. **music.mp3** — เพลงคลอตอนเปิดการ์ด แนะนำแนว aesthetic / lofi / acoustic เบาๆ
   หาได้จากแหล่งฟรีลิขสิทธิ์ เช่น Pixabay Music (https://pixabay.com/music/) หรือ YouTube Audio Library
   วางไว้โฟลเดอร์เดียวกับ `index.html`

⚠️ **สำคัญ:** ตั้งชื่อไฟล์ให้ตรงเป๊ะ `photo1.jpg` และ `music.mp3` (ตัวพิมพ์เล็กทั้งหมด ไม่มีนามสกุลซ้อนกัน เช่น
ไม่ใช่ `photo1.jpg.JPEG`) ถ้าเครื่องคุณซ่อนนามสกุลไฟล์อยู่ ให้เปิดดูให้เห็นนามสกุลจริงก่อน rename

หากไม่มีไฟล์ใดไฟล์หนึ่ง การ์ดจะยังใช้งานได้ปกติ แค่จะไม่มีรูป/เสียงเพลงเท่านั้น

## วิธีอัปโหลดขึ้น GitHub Pages (ฟรี)

1. สร้าง repository ใหม่บน GitHub เช่น `birthday-card-ploy` (ตั้งเป็น Public)
2. กด **Add file > Upload files** แล้วลากไฟล์ `index.html`, `README.md`, `photo1.jpg`, `music.mp3` เข้าไปพร้อมกัน แล้วกด **Commit changes**
3. ไปที่ **Settings > Pages**
4. หัวข้อ **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอสักครู่ จะได้ลิงก์ประมาณ
   `https://ชื่อผู้ใช้.github.io/birthday-card-ploy/`
6. คัดลอกลิงก์นี้ไปแชร์ให้พลอยได้เลย 🎉

## ปรับแต่งข้อความ/สี

- ข้อความคำอวยพรอยู่ใน `<div class="letter-body">` ในไฟล์ `index.html`
- เปลี่ยนสีธีมได้ที่ตัวแปรด้านบนของไฟล์ในส่วน `:root { ... }`
